# Previews (coming)

   through its best patch (plan: E-minor keys so patches A/B easily).

   approximation renderer, labeled if approximate).
3. **Per-family clips** — 10-15s per family folder, linked from the main README.
4. **Phrase-through-patch demos** — show phrase packs played by matching instruments.
